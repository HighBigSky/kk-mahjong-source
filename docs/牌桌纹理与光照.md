# 牌桌纹理与光照

全场沿用右侧、略偏前上方的一盏灯：灯位92%/32%，牌体的255°渐变、投影向量(-1,.25)不变。此次只改桌边材质与背景分配，不动桌框尺寸、位置、透视、裁剪、z-index、DOM圆角、内边距或牌区坐标。

## 圆润实木剖面

木边采用同一套17节点剖面：深棕外缘 → 中棕过渡 → 浅棕圆润高光 → 中棕上表面与低对比细纹 → 内缘亮倒角 → 深棕压槽。外、内倒角宽度均为1.5px，画在原有背景中，不新增几何边框或改变厚度终点。

主色为浅棕 #bd9664、中棕 #795939、深棕 #493426。中段木纹的细小明暗节点只相差约10/255级，不用平涂色块；一层连续角向布光让右侧更亮、近端更暗。顶部剖面最亮，外侧面次之，下缘最暗，产生近端更厚、远端更薄的观感。金线原4px嵌入槽与亮/中/暗三色、1px亮边/暗边保持。

## 沿桌边转弯的木纹

旧木纹使用同心椭圆场，虽能跨过斜接角，却不平行于四条直桌边。新模型用两片直边场和四片圆角场覆盖同一个木框：

- 直边以离外缘的内缩距离d读取同一剖面，等色线平行于桌边。
- 四角以R-r读取反向排列的同一剖面，等色线绕角成弧。
- 圆角与直边交界处共用节点、相位和切线，覆盖片段恰好衔接，不分四块木板重置纹向。
- 木纹转弯的背景绘制半径R至少为木边带宽加3px，让内侧纹线保有弧度。它只控制背景图案，桌框原DOM外径完全不变；不扩大桌角、不改clip-path。
- 木边带宽为桌框绘制宽度的4.2%，细纹节点随它等比变化。外缘倒角仍为固定1.5px。

一层首尾同色的连续角向光照跨越所有木纹片段，右侧受暖光、左侧与近端压暗；不在拼角处单独叠四块高光。

## 每层不超过八张背景

横屏 .table::before 共8层：连续木质布光、四角木纹4层、两方向直边木纹2层、原台呢底色/主布光1层。

原 .table-border 共8层：横/纵压槽与嵌线2层、经纬织纹2层、原中央及常触碰区磨痕2层、原绒面反光1层、原台呢底色/主布光1层。原绒毛噪点单层被收敛，以满足本轮八层预算；经纬、两种磨痕、反光与台呢主色不变。背景仍按原尺寸绘制，以现有 .43F 投影中心对齐，不改容器几何。

中央面板1.5px浅凹、骰子、点坑、原椭圆金环、四家牌体、HUD与离房按钮均保留。房间右亮左暗、桌底近重远轻的落地阴影不变。原裁掉的上下桌沿和角部继续沿原取景裁掉，不为展示新木纹更改取景。

单绘制元素的box-shadow最多两层。没有新增DOM、图片、filter、backdrop-filter或依赖；旧 assets/table-square-frame.svg 文件保留，运行中的桌框背景不引用它。
