# 牌桌纹理与光照

当前全场材质光照由 `table-depth.css` 集中定义，牌体、骰子、座位卡、操作按钮、HUD与弹窗复用。桌框尺寸、缩放、透视矩阵、裁剪、层级、圆角、内边距和牌区位置保持原值；不修改规则。

## 单一右侧灯光

以用户最新指定为准：灯在右侧、略偏前上方，替代此前的左上／右上口径。高光坐标 `92% / 32%`、明到暗渐变角 `255deg`、投影向量 `(-1, .25)`；高光共用暖白 `#fff5df`，暗部共用暖中性 `rgb(30 26 18)`。

`src/ui/tile-material.js` 从CSS读取这一灯位，以真实整牌旋转反向变换高光、投影与顶边法线。左右90°与对家180°牌河在投影后仍右亮左暗，不能把灯随牌转走。痞子悬停不再用135°覆盖场景灯位。象牙牌面、牌背主色与原SVG图案不重画。

## 阴影与性能

接触阴影、短主影、环境遮挡的比例统一为基准宽度的2.5%、4.5%、9%。牌体从真实牌宽推导，沿用手牌／副露／牌墙／牌河 `1 / .8 / .6 / .4` 强度；HUD等控件从同组比例与场景单位推导。大范围AO留在场景和桌框容器，不再每张牌重复叠第三层柔影。

牌体、现有两个伪元素和SVG各自的 `box-shadow` 堆叠均不超过两层。双倒角合并为双内影，牌背浮雕为双内影，边缘高光为单内影。摸／补槽原描边环替代主影，占第二层预算。选中和最后出牌是一层向左短投影加一层状态光晕，取消状态立即撤去外影。正常态内影始终在牌框内，CSS内影偏移与外投影相反，以便暗部落在左内缘，不污染邻牌。

全局弹窗的 `backdrop-filter` 已移除，对局不使用滤镜。牌体动画和过渡只允许 `transform`、`opacity`，材质和阴影即时切换；手牌沿用120ms与原缓动、抬起距离，不逐帧插值颜色或阴影。后续薄面板控件按用户新口径额外允许 `background-color` 过渡，详见[界面面板材质](界面面板材质.md)；灯位、渐变图片与阴影仍不做动画。

## 主桌面的十一层背景

横屏 `.table::before` 不加载木框 SVG，使用十一层 CSS 渐变：

1. 横向内壁、压槽与木头中的金属嵌线：原台呢边界不变，绘制范围向外扩4px，含金属亮／中／暗三段和原2.5px暗槽；内壁左暗右亮，连续渐入槽底和内缘高光。
2. 纵向内壁、压槽与嵌线，与横槽共用绘制矩形及中心，近端更暗、远端略亮，四角交叠闭合，不增加几何边框。
3. 90° 经纬细纹，周期为桌框宽度的 0.18%，纤维宽度为周期的 24%。
4. 0° 交错细纹，沿用相同周期，以明暗交错表现织物接触。
5. 低对比重复径向绒毛，单色透明度最高约 1.6%；基础周期为桌宽的 0.11%。
6. 中央宽幅使用不均，最高透明度约2%，渐隐至透明，不重复。
7. 常触碰区域的第二层使用不均，最高约2.4%，宽幅渐隐，不形成硬边图案。
8. 沿场景255°方向的一条宽幅绒面反光带，暖白峰值透明度为10/255（约3.9%），右侧偏亮，两端渐隐；只画在原台呢范围。
9. 位于场景灯位92% / 32%的柔和径向布光，从 `#326b53` 经 `#1b5543` 过渡到 `#0a3027`，亮部收敛以保持牌面、台呢、背景的明度层级。
10. 周期为桌宽0.5%的细木纹。
11. 周期为桌宽3.8%的生长纹，颜色在深棕、中间色、暖色亮部之间连续变化。

两组木纹统一使用50%／50%的中心，各周期首尾同色；整块框体只用一个连续渐变场，不在四个斜接角处分四边切换纹向。所有纹距从 `.table` 的 `--table-texture-width` 推导，对局中即原 `--table-frame-size`，不引入设备分支或固定像素纹距。非横屏基础材质也复用这些变量。

七层台呢背景沿用原中心绘制区域：宽为 `0.916 × 桌框宽度 − 2 × 原左右裁边`，高为 `0.916 × 桌框宽度`。压槽／嵌线层在宽高上各加8px，把4px金属带放到台呢外的木框中，原台呢边界、织纹和压槽深度不变。0.916来自原SVG内沿。所有变化仅为背景绘制，不是DOM尺寸或布局内边距。

`assets/table-square-frame.svg` 文件保留，不删除仓库资产。不新增图像、DOM、滤镜或依赖。主桌面11层、桌框叠光7层、原椭圆装饰2层、中央实体面板3层；房间背景5层、原环境伪元素4层，所有绘制元素各自不超过12层。桌体、中央区及骰子的每层阴影都不超过两层。

## 嵌线、边角与厚度

- 金属主色为亮 `#e9d49d`、中 `#bb965c`、暗 `#694625`，亮度低于牌面高光。原椭圆双线的边框宽度／样式／圆角保持不变，边框改透明，以4px径向金属环绘制可见线体；上缘1px亮内影，下缘1px暗内影，不用纯色填满中心。
- `.table-border` 保留原几何，用AO内影和一层极淡边缘反光收口。四角用局部低强度渐变表达抛光，右侧更亮；渐隐在绘制片段边界之前归零，不产生矩形断口。
- 中央 `.table-center` 及原有 `::before` 表达1.5px内凹，右侧受光、左侧暗部与投影。细金边与原方向色分区保留，骰子的位置和半径不变；骰身微凸光照与点坑双内影均取右侧灯光。
- `.table::before` 的侧壁和落影合并为两层，仍朝左；原厚度终点保留，不改变任何DOM矩形。落影沿原偏移加深并柔化，中间材质层次由木纹与光照渐变承担。
- 远端叠加渐隐的低亮暖中性色，最远端细木纹对比降低约30%，到38%位置归零；近端纹理保持原对比。只通过渐变降低锐感，不使用模糊滤镜。
- 内壁宽度复用原2.5px压槽，左壁为 `#0b1f15cc`、右壁为 `#71917199`，各自经过中间色进入相同槽底；不新画几何边框，四面与角部由相交的连续渐变衔接。
- `#game` 用暗角、右侧环境光、左侧压暗、底部微反射和深色底五层渐变表达房间；灯位与牌体统一为92% / 32%，不画墙纹。
- 桌框原 `clip-path` 会裁掉框外投影，因此桌底接触阴影复用原 `#game::before`。近端阴影峰值为143/255、远端36/255；两块椭圆在各自70%处已完全透明，不露矩形绘制片段边缘。原环境光与暗角保留，伪元素的尺寸、层级、定位及点击穿透不变；不改裁剪来迁就阴影。

## 验证

`tests/ui-scene-light.mjs` 保留全场光照／几何回归，并核对主桌面11层、不超过12层的预算。`tests/ui-table-materials.mjs` 以本轮修改前的 `306e39b` 为基线，在640×360、844×390、1920×1080下严格对比桌面、桌框、中央区、骰子、点坑、方向字及镜像方向字、各牌区和HUD的矩形与伪元素几何，核对z-index、transform、clip-path、圆角与内边距均不变。

材质专项读取1.5px内凹、双1px金属边、金属渐变、两层阴影、11层背景、低对比磨痕和远端对比衰减；新增2.5px内壁四面用色、四角交叠、近远落影强度、房间左右亮度与右侧反光带检查。木纹按浏览器计算的渐变周期／颜色节点建立同一连续场，在四条斜接线两侧取解析样本，比较相位、颜色和切线；房间和绒面反光也由计算样式做解析采样，这不是屏幕截图取色。原取景裁掉的框角仍保持原裁剪，不为显示角部改变取景。

对比度按计算色值估算：最暗正常象牙色 `#e8dfc9` 对最亮台呢 `#326b53` 再叠20%暖白反射，约3.09:1；这是材质主色的保守估值，不声称已逐像素采样，也不把牌字、状态角标、木沿当成绒布主色。

完整布局验收继续使用 `tests/ui-layout-acceptance.mjs`；设置 `KK_UI_SCREENSHOTS=0`。所有验证只读取计算样式与几何，不生成截图，不声称进行了逐像素材质采样。
