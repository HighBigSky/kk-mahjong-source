# 牌桌纹理与光照

当前全场材质光照由 `table-depth.css` 集中定义，牌体、骰子、座位卡、操作按钮、HUD与弹窗复用。桌框尺寸、缩放、透视矩阵、裁剪、层级、圆角、内边距和牌区位置保持原值；不修改规则。

## 单一右侧灯光

以用户最新指定为准：灯在右侧、略偏前上方，替代此前的左上／右上口径。高光坐标 `92% / 32%`、明到暗渐变角 `255deg`、投影向量 `(-1, .25)`；高光共用暖白 `#fff5df`，暗部共用暖中性 `rgb(30 26 18)`。

`src/ui/tile-material.js` 从CSS读取这一灯位，以真实整牌旋转反向变换高光、投影与顶边法线。左右90°与对家180°牌河在投影后仍右亮左暗，不能把灯随牌转走。痞子悬停不再用135°覆盖场景灯位。象牙牌面、牌背主色与原SVG图案不重画。

## 阴影与性能

接触阴影、短主影、环境遮挡的比例统一为基准宽度的2.5%、4.5%、9%。牌体从真实牌宽推导，沿用手牌／副露／牌墙／牌河 `1 / .8 / .6 / .4` 强度；HUD等控件从同组比例与场景单位推导。大范围AO留在场景和桌框容器，不再每张牌重复叠第三层柔影。

牌体、现有两个伪元素和SVG各自的 `box-shadow` 堆叠均不超过两层。双倒角合并为双内影，牌背浮雕为双内影，边缘高光为单内影。摸／补槽原描边环替代主影，占第二层预算。选中和最后出牌是一层向左短投影加一层状态光晕，取消状态立即撤去外影。正常态内影始终在牌框内，CSS内影偏移与外投影相反，以便暗部落在左内缘，不污染邻牌。

全局弹窗的 `backdrop-filter` 已移除，对局不使用滤镜。动画和过渡只允许 `transform`、`opacity`，材质和阴影即时切换；手牌沿用120ms与原缓动、抬起距离，不逐帧插值颜色或阴影。

## 主桌面的八层背景

横屏 `.table::before` 不加载木框 SVG，使用八层 CSS 渐变：

1. 横向两边的压槽：在原台呢边界内绘制 2.5px 暗槽、0.6px 内缘高光与0.6px渐隐。
2. 纵向两边的相同压槽，与横槽共用绘制矩形及中心，四角交叠闭合，不增加几何边框。
3. 90° 经纬细纹，周期为桌框宽度的 0.18%，纤维宽度为周期的 24%。
4. 0° 交错细纹，沿用相同周期，以明暗交错表现织物接触。
5. 低对比重复径向绒毛，单色透明度最高约 1.6%；基础周期为桌宽的 0.11%。
6. 位于场景灯位92% / 32%的柔和径向布光，从 `#326b53` 经 `#1b5543` 过渡到 `#0a3027`，亮部收敛以保持牌面、台呢、背景的明度层级。
7. 周期为桌宽 0.5% 的细木纹。
8. 周期为桌宽 3.8% 的木材生长纹，颜色在深棕、中间色、暖色亮部之间连续变化。

两组木纹的椭圆中心略错开，沿四边连续转向。所有纹距从 `.table` 的 `--table-texture-width` 推导，对局中即原 `--table-frame-size`，不引入设备分支或固定像素纹距。非横屏基础材质也复用这些变量。

压槽与四层台呢背景共用同一个中心绘制区域：宽为 `0.916 × 桌框宽度 − 2 × 原左右裁边`，高为 `0.916 × 桌框宽度`。0.916 来自原 SVG 两侧各 42/1000 的内沿，保留原双 SVG 偏移后直边部分的木沿宽度。这里仅是背景绘制尺寸，不是 DOM 尺寸或布局内边距。

`assets/table-square-frame.svg` 文件保留，不删除仓库资产。不新增图像、DOM、滤镜或依赖；主桌面8层，既有桌框层2层，中心装饰层1层，场景背景3层与环境光2层，各绘制元素均不超过8层。基础样式的绒布为6层。

## 嵌线、边角与厚度

- 原金线仍是相同位置、宽度与圆角的双线，仅改为低透明度暖金色，上缘略亮、下缘略暗；亮度低于象牙牌面的高光。
- `.table-border` 沿用原几何与一个AO内影，叠加右侧极淡高光：右侧亮、左侧暗。
- 中心微凹复用 `.table-border::after`，在原金线内增加最高约14%的暗底径向渐变，最外沿全透明；两个模糊内阴影表达凹入与反射，不增加圆形硬边或改变原圆角。
- `.table::before` 保留三段实体侧壁与一层落影，共四层；绘制偏移统一朝左，颜色从高光、中间色到阴影递进。装饰阴影不是DOM厚度，不改变矩形、裁剪或牌区坐标。
- `#game` 用柔和暗角连接桌外背景，灯位与牌体统一为92% / 32%；环境伪元素只使用软径向渐变，尺寸、层级与定位不变。

## 验证

`tests/ui-scene-light.mjs` 与基线 `5bbe071` 对照，在640×360、844×390、1920×1080下逐一比较全部可见场景元素、牌、HUD、按钮与伪元素的矩形及几何属性，要求严格相等；同时检查四家旋转后的光照、两层阴影预算、无滤镜、只动画transform／opacity及亮度层级。`tests/ui-table-materials.mjs` 保留八层渐变、织纹比例、压槽、微凹与原几何验收，同步新灯位及朝左的侧壁绘制。

对比度按计算色值估算：最暗正常象牙色 `#e8dfc9` 对最亮台呢 `#326b53` 再叠20%暖白反射，约3.09:1；这是材质主色的保守估值，不声称已逐像素采样，也不把牌字、状态角标、木沿当成绒布主色。

完整布局验收继续使用 `tests/ui-layout-acceptance.mjs`；设置 `KK_UI_SCREENSHOTS=0`。所有验证只读取计算样式与几何，不生成截图，不声称进行了逐像素材质采样。
