# 牌桌纹理与光照

本轮只修改 `table-depth.css`、`landscape.css` 的材质变量、背景、边框颜色及阴影颜色/模糊。桌框尺寸、缩放、透视矩阵、裁剪、层级、圆角、内边距和牌区位置保持原值；不修改麻将牌模型或规则。

## 主桌面的六层背景

横屏 `.table::before` 不再加载两张偏移的木框 SVG，而是使用六层 CSS 渐变：

1. 90° 经纬细纹，周期为桌框宽度的 0.18%，纤维宽度为周期的 24%。
2. 0° 交错细纹，沿用相同周期，以明暗交错表现织物接触。
3. 低对比重复径向绒毛，单色透明度最高约 1.6%；基础周期为桌宽的 0.11%。
4. 位于绒布绘制区域 35% / 30% 的柔和径向布光，从 `#38775d` 经 `#1b5543` 过渡到 `#0a3027`，中心偏左上、四周压暗。
5. 周期为桌宽 0.5% 的细木纹。
6. 周期为桌宽 3.8% 的木材生长纹，颜色在深棕、中间色、暖色亮部之间连续变化。

两组木纹的椭圆中心略错开，沿四边连续转向。所有纹距从 `.table` 的 `--table-texture-width` 推导，对局中即原 `--table-frame-size`，不引入设备分支或固定像素纹距。非横屏基础材质也复用这些变量。

四层台呢背景共用同一个中心绘制区域：宽为 `0.916 × 桌框宽度 − 2 × 原左右裁边`，高为 `0.916 × 桌框宽度`。0.916 来自原 SVG 两侧各 42/1000 的内沿，保留原双 SVG 偏移后直边部分的木沿宽度。这里仅是背景绘制尺寸，不是 DOM 尺寸或布局内边距。

`assets/table-square-frame.svg` 文件保留，不删除仓库资产。本轮不新增图像、DOM、滤镜或依赖；对局主桌面每个背景均为渐变，层数为 6，既有 `.table-border` 与嵌线不增加背景。基础样式的绒布为 4 层，所有绘制元素都不超过 6 层。

## 嵌线、边角与厚度

- 原金线仍是相同位置、宽度与圆角的双线，仅改为低透明度暖金色，上缘略亮、下缘略暗；亮度低于象牙牌面的高光。
- `.table-border` 沿用一个内阴影，用更宽、更柔和的暗部表现凹入边沿与略暗的木角；不增加遮挡层。
- `.table::before` 保留三段侧壁与一层落影，共四层阴影。四层 XY 偏移保持原值，只调整颜色及模糊：侧壁由暖亮棕过渡到中棕、深棕，落影保持柔和。

## 验证

`tests/ui-table-materials.mjs` 与基线 `19d3284` 对照，在 640×360、844×390、1920×1080 下逐一比较桌体、桌框、手牌、副露、牌河、牌墙和牌堆槽位的矩形及几何属性，要求严格相等。同时检查六层纯渐变、无滤镜、纹距/桌宽比例、四层阴影及其原偏移、金线对比度。

完整布局验收继续使用 `tests/ui-layout-acceptance.mjs`；设置 `KK_UI_SCREENSHOTS=0`。所有验证只读取计算样式与几何，不生成截图，不声称进行了逐像素材质采样。
