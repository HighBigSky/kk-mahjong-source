# 手机横屏轻透视牌桌

当前要求：桌上牌区整体贴合桌面透视，看起来放在绒布上，保留麻将牌建模。牌河、牌墙及另外三家的手牌/副露共用桌面平面，取消各自抵消俯仰的正视显示。自己的手牌及相邻副露继续沿用之前确认的正视操作方式。

牌体样式和素材不改，包括原始长宽比、厚度、倒角、材质、高光和阴影。不改规则、发牌、计分、协议，不新增依赖或设备分支。建房及等待页继续竖屏，手机和 PC 共用横屏对局布局。

## 关键参数

W、H 为安全区内舞台宽高；PC 高窗口使用居中 16:9 舞台。项目使用 CSS 3D。

| 参数 | 当前值 |
| --- | --- |
| 桌面进深 | T = min(.64W, 1.35H)，逻辑宽 L = 7T/9 |
| 方桌木框 | 宽、深均为 1.10T，素材 contain 等比显示 |
| 原桌面相机 | perspective(2T) rotateX(46deg)，不变 |
| 原桌面位置 | left: .5W - L/2; top: .98H - .9236T，不变 |
| 三家排列基准 | 方桌原始平面中心；对家水平居中，左右在同一桌深居中 |
| 原等比系数 | 对家牌河 .70、左右牌河 .90、手牌/副露及牌墙 .72；不单独压缩某一轴 |
| 牌河容量 | 每家 36 格，上下 9×4、左右 4×9，间隙 0，时间顺序和朝向不变 |
| 本家手牌 | 原正视操作布局，宽 .66W，中心 .5W，底边 .985H；牌数变化仍居中 |
| 本家前墙 | 原位 17 墩，起点 13.75L/70、步长 2.5L/70，不变 |

先从原投影反算牌区位置，在桌面坐标中等比缩放和平移，再交给原桌面相机。各家仍为手牌/副露在外、牌墙在中、牌河在内。边缘遵循同一透视消失方向，不强制成为屏幕上的平行线。

屏幕中的梯形、近大远小属于视角变化，不是修改模型。测试先把实牌四角反投影回方桌坐标，再检查矩形、直角和原始长宽比；不能用屏幕外接矩形判断牌体是否变形。

## 动画与交互

- 其他三家开局飞牌从真实牌墙四角飞向真实手牌四角；自己的飞牌轨迹沿用原样。
- 最新弃牌沿真实牌河平面原位放大，密集牌河按可用空间限制倍率；缩回落到原实牌四角，不拉伸到外接矩形。
- 动画不移动底下的牌河节点，不改变 136 个牌墙槽位的身份和顺序。
- 命中区域随 DOM 容器投影更新。本家手牌、按钮、方向文字、杠型标签、摸补标记及提示面板保持正视。
- 桌框、灯光、环境、中央骰子区、头像和 HUD 不变。游戏引擎、服务器和网络模块不变。

## 涉及文件

- src/ui/flat-opponents.js：三家牌区共用桌面平面；提供实牌平面测量与 CSS 矩阵转换给动画复用。沿用模块路径。
- app.js：弃牌放大/缩回共用实牌投影，删除旧正视角度、缩放分支及单独相机反算。
- src/ui/opening-deal.js：他家飞牌首末帧使用实牌投影，保留本家原轨迹。
- tests/browser-geometry.mjs：独立的方桌反投影测量。
- tests/ui-seated-view.mjs：在桌面坐标检查模型比例、桌边方向、居中和分层，继续检查实牌可见性和输入。
- tests/ui-layout-acceptance.mjs：反投影检查牌河原始比例，比较密集牌河放大牌和实牌四角。
- 本文件更新说明；牌体样式、纹理和素材未修改。

## 验证范围

- Edge 触屏模拟：640×360（16:9）、844×390 和 780×360（约 19.5:9）、800×360（20:9）；PC 1920×1080。
- 15 个满牌/最多副露、20 个手牌数量和 20 个真实 HTTP/SSE 输入场景。实牌在绒布内、无滚动和遮挡，原始模型比例与上一版相同，本家牌区、HUD、相机及桌框不变。
- 24 个牌河布局和 24 个弃牌稳定性场景：每家 36 张压力弃牌，紧密、不重叠、动画后位置不跳；密集牌河放大牌与实牌四角误差小于 .8px。
- 8 个开局动画场景：53 张、四张一组、他家只显示牌背、锁定输入、不重复播放、旋转与离房清理；末帧与实牌四角误差小于 .8px。
- 现有规则及网络单元测试、项目 TypeScript、JavaScript 语法与 git diff --check。

报告、截图保存在忽略入库的 output/ui-seated-view.json、output/ui-layout-acceptance.json、output/opening-deal-verification.json 和 output/seated-view-*.png。实体 iOS/Android 尚未逐机测试。

## 手测

1. 手机竖屏建房，开局后横置；等待页仍竖屏。
2. 查看左右和对家牌区贴合绒布、近大远小，原牌体厚度、倒角、材质保留。
3. 满牌牌河完整可见且无缝隙、重叠；最新弃牌原位放大缩回。
4. 开局四张一组飞牌准确落位；旋转、离房时清理动画和输入锁。
5. 本家单击、双击、特殊杠保持原样，1/2/7/14 张手牌居中；操作按钮和胡牌提示仍可点击。
