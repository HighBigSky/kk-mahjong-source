# 手机横屏轻透视牌桌

当前状态：四家手牌保持定向回退后的平面牌列，牌河保持紧密排布，见 [手牌牌河定向回退](手牌牌河定向回退.md)。桌框保持 1:1 方桌，在方桌版本上整体等比放大 12%，本家手牌大小不变。

按最后确认的要求：本家手牌保持平直、水平居中；只有牌桌与桌上实物带轻微坐席透视。此次不改规则、发牌、计分、协议，也不新增依赖或设备分支。手机和 PC 共用现有横屏布局，建房与等待页继续竖屏。

## 关键参数

项目使用 CSS 3D，没有米制场景与真实摄像机，因此不虚构厘米位置。以下为可直接调节并实测的投影参数。W、H 均指扣除安全区后的横屏舞台宽高；PC 高窗口沿用居中的 16:9 舞台。

| 参数 | 最终值 |
| --- | --- |
| 桌面倾斜 | `rotateX(46deg)`，对应约 44° 向下观察，较首版强第一人称方案更轻 |
| 透视焦距 | `perspective(2.016H)`，随桌面同步放大，保持投影形状与牌面比例 |
| 投影中心 | `(50%W, 52%H)` |
| 逻辑内容区 | 宽 `L = .784H`，进深 `T = 1.008H`；由统一系数 `--table-scene-scale:1.12` 控制 |
| 实物木框 | 宽、深均为 `1.008H`，源宽深比 `1:1`；`table-square-frame.svg` 四边等宽、角部斜接，使用 `contain` 等比显示 |
| 桌面定位 | `left: 50%W - L/2; top: .52H - T/2`（约 `.016H`），变换原点居中 |
| 投影后比例 | 近沿约 `69.1%W`（16:9）～`55.3%W`（20:9）；可见进深约 `72.4%H`，方桌在透视下自然呈梯形 |
| 桌面上/下边缘 | 约 `22.3%H` / `94.7%H`，下方保留木边厚度和阴影 |
| 本家手牌 | 不旋转、不扇形、不受桌面透视；宽 `.66W`，中心 `50%W`，底边 `98.5%H` |

| 左右暗手 | 以桌面中心向两侧 `.43 × 木框源宽` 定位，保留平面牌列，无单独侧转，暗牌只显示牌背 |

| 中央骰子区 | 宽高 `14L/70`；水平居中，上边缘 `.5T - 9.5T/70` |
| 操作与提示 | 操作区沿用原先屏幕坐标；「提示」入口仍在手牌左侧，胡牌卡片在手牌右上方，均不倾斜 |

桌框没有 `scaleX` 压缩，也未缩放整张屏幕。原长方形木框文件保持原样，新方框素材的 `viewBox` 为 `1000×1000`，保留原木纹和暖色材质。桌内牌按可用格位计算同一宽高比例的尺寸；左右牌河继续使用已确认的 `1.44` 平面纵向补偿，出牌放大与缩回共用该比例，每家仍有 36 个紧密格位。

本次将桌面、桌上三家手牌、牌墙、牌河和透视距离围绕原投影中心同步放大 12%，投影面积约增加 25%。不单独横向拉宽，桌上牌面长宽比、接缝与相对锚点不变。本家手牌、外侧头像与操作区、颜色、灯光及环境设置沿用原版。

## 文件改动

- `landscape.css`：统一放大系数作用于桌宽、桌深、透视距离，定位保持投影中心不变；本家手牌与 HUD 不参与缩放。
- `tests/ui-seated-view.mjs`：按原投影尺寸 × 1.12 验证实际宽度和深度；保留方桌、无遮挡、满河与输入检查。
- `docs/轻透视牌桌布局.md`：更新放大后的尺寸与定位参数。桌框素材、游戏逻辑和其他文件不变。

关键样式位于 `landscape.css` 的坐席视角区。桌面实际变换仍只在 `.table` 上，文字与本家手牌为舞台上的兄弟节点。CSS 与实际 DOM 共用浏览器命中区域，没有另造点击坐标。

## 观感变化

桌框仍为正方形，近沿自然较宽、远沿较窄，左右保留环境空间。相比上一版桌子更贴近玩家，占屏面积增加约四分之一；三家暗手与牌河同幅放大而不变形，本家手牌保持原来的大小与平直排布。

## 手测与边界

1. 手机竖屏创建房间，开局后横置；确认等待页仍竖屏，对局只有一套横屏布局。
2. 检查桌沿有轻微收窄、木边厚度，自己的牌为平直排布。切换 16:9 与 20:9，牌面不能被拉伸。
3. 从手牌左、中、右分别单击选中、再次点击普通牌出牌；特殊牌在 300ms 内双击开杠。操作后提示面板与手牌中心不得横移。
4. 牌数减少并出现碰杠副露时，检查剩余手牌仍居中；点击提示先高亮、再次点击确认。
5. 牌河满牌时检查四区都完整可见；最新弃牌应在原位置放大，下一家操作后原位缩回。
6. 检查方向、杠型、翻皮墩号、摸补文字为正向清晰文字；操作按钮可正常点击。

实体 iOS/Android 设备尚未逐机测试；本轮使用 Edge 触屏模拟。牌、按钮、玩家信息均须完整可见。
