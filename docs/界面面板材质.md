# 界面薄面板材质

座位卡、头像框、金币／房间码／余牌／痞子癞子小结、连接胶囊、按钮和弹窗共用 `resin-panel-v1`。本轮只修改 `styles.css`、`seats-layout.css`、`landscape.css`，不增加DOM、图片、依赖或修改游戏逻辑。

## 统一参数

`styles.css` 的 `--ui-panel-*` 定义材质。主色为 `#3a5c49`，行动者的同族绿色为 `#426b50`；光泽使用场景暖白 `#fff5df`，阴影使用 `rgb(30 26 18)`。灯位直接引用上一轮场景的 `92% / 32%`，不另设左上光。

背景在元素自身求值，包含四层渐变：1px右边缘高光、右侧柔和釉面、2%级微凸曲面、左侧内缘压暗。头像照片和插画原文件不改，材质只作用于现有框体及投影。所有原尺寸、位置、间距、圆角、叠放次序与热区保留。

- 座位卡：共享微凸涂层，一层左内缘暗部与一层向左短投影；四席共用参数，不按座位方向另写光照。名字、金币和状态的原有字号、字重及语义色不变。行动、操作提示、语音和离线状态保留原强调边框或字色。
- HUD：四个胶囊使用完全相同的主色、涂层和凹槽内影；连接状态胶囊复用这一档。数字保留现有 `tabular-nums`、原字体和固定占位，不额外切换lining数字，以免改变金币文本宽度。
- 按钮：主／次按钮、吃碰杠胡、设置／提示和弹窗按钮复用同一涂层。悬停将灯斑横坐标从92%移到98%，按下改为两层内凹阴影；禁用状态移除渐变高光和外影，降低底色对比。原吃碰杠胡、过、语音和房间操作的语义色不改含义，原按下位移保持不变。
- 弹窗：卡片使用同组主色与右侧涂层、左向投影；标题和正文的对比独立于背景反光。房间邀请区和文本输入框使用凹槽档位。所有弹窗遮罩为72%中性黑，只压暗、不染绿，旋转引导的遮罩相同。

每个元素最多两层 `box-shadow`。普通面板是一层内影加一层左向投影；按下态是两层内影；当前行动者／说话头像用原状态环替代其中一层，不叠第三层。无 `backdrop-filter` 或大面积 `filter`，不新增伪元素。面板控件的过渡仅有 `transform`、`opacity`、`background-color`，统一120ms与 `cubic-bezier(.2,.7,.2,1)`；灯位、渐变图片与阴影不参与动画。牌体原过渡范围不变。

亮度关系按材质主色核对：象牙牌面 `#f6efdd` > 面板 `#3a5c49` > 台呢 `#1b5543` > 桌外背景。按钮沿用语义色，浅色提示框沿用象牙族，并保持低于牌面亮部。

## 验证

`tests/ui-panel-materials.mjs` 以 `b7442ff` 为基线，在同一真实HTTP／SSE房间中热换三张样式表，严格对照可见控件及桌面区域的矩形和几何／字体属性，不使用截图。覆盖：

- 360×640创建和等待房间，含离线状态；
- 640×360、844×390、1920×1080的四席、四个HUD胶囊、行动／操作／语音／离线文字；
- 主次按钮及吃碰胡／过／设置的普通、悬停、按下、禁用状态，使用CDP伪类，不发送对应游戏动作；
- 设置、规则、选牌、出牌记录、语音、结算六类弹窗；
- 共享变量、右侧高光与左向投影、两层阴影预算、中性遮罩、等宽数字、亮度关系与过渡属性。

完整回归使用 `npm test`、`tests/ui-room-hud.mjs`、`tests/ui-layout-acceptance.mjs`。HUD套件新增对 `KK_UI_SCREENSHOTS=0` 的支持，使本轮全部验证不产出截图。

结果来自计算样式、DOM几何与材质色值，不等同于真机逐像素或帧率测量。发布沿用AGENTS要求：推送当前分支、云端备份、仅同步静态资源，不重启服务，并验证在线资源哈希、首页、健康接口及PID。
