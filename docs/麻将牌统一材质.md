# 麻将牌共享材质与可见面

所有正面、牌背复用 `tiles-depth.css` 中的 `resin-v9` 模型。区域规则只选择四种档位、可见面和整牌光照旋转补偿，不维护第二套釉面、倒角或接触阴影。

## 材质层

- `--tile-gloss`：低于 8% 的斜向釉面、两层低对比象牙质感和极轻的下沿暗化，位于透明 SVG 下方。
- `--tile-model-face-curve`：中心位于50%/44%的微凸径向光照，中心白光与边缘暖暗的最大透明度均为13/255（约5.1%）。它位于细纹之后、原釉面之前，仍在透明SVG下方，不遮挡图案。
- `--tile-model-face-shadow`：保留右上外倒角和右缘次级倒角宽度；视觉左侧的两级明暗带均限制在1px内。
- `--tile-model-edge-contact-shadow`：视觉左缘不超过1px的无模糊接触暗线。
- `--tile-model-contact-shadow`：三层牌内接地暗部（紧实 AO、主暗部、柔和过渡），全部为 inset，不向邻牌投影；正面层也复用它，避免被牌面覆盖后失去立体感。
- `--tile-model-raised-shadow`：只有选中、提示、最后出牌可以使用的三层外投影，入态通过共享透明度渐入；取消状态时同步撤回，不对 box-shadow 做退出动画。
- `--tile-model-edge-shadow`：顶面、侧面转角共用的柔和内高光，随统一圆角连续收口，不另画一圈硬边。
- `--tile-model-face-grain`：低于5%的重复渐变细纹；牌字仍在材质上方，不改变图案。
- `--tile-model-back-weave`：两条低于6%总强度的重复渐变织纹，只在牌背绘制一次。
- `--tile-model-transmission`：不超过1px的透光环。倒角与接触暗部按实牌宽度推导；牌字区域用不超过1px的内阴影表达凹陷，图案不变。
- 牌背使用相同的釉面与倒角，在绿色牌背变量上叠加外框高光、内框浮雕；暗手底部的象牙薄层不作为通用底面推广到牌墙。

## 牌面主色、图案与过渡

正常态的牌面亮部、主色、暗部分别取自`--tile-face-normal-light: #fffef6`、`--tile-ivory: #f6efdd`与`--tile-face-normal-shade: #e8dfc9`。共享的`--tile-face-light`、`--tile-face-base`、`--tile-face-shade`组合成同一条牌面渐变，手牌、牌河、副露、翻开的牌墙实牌、选牌弹窗、结算和小标记不再分别定义底色；绿色牌背继续使用原牌背色变量。

图案精灵图`assets/tiles.svg`的文件字节、路径、填充色与原描边属性保持原样。加载器把所有带`stroke-width`且未明确关闭描边的图形原宽度记录为`--tile-glyph-base-stroke`，包括白板中继承上层描边色的图形，并给现有图形添加`tile-glyph-stroked`类，让引用实例能直接匹配共享CSS，不依赖精灵图祖先选择器穿过`use`的引用边界。`tile-material.js`复用已读取的实际牌宽，以数值`12 / 牌框短边`写入`--tile-model-glyph-accent`；CSS默认值为0，不依赖浏览器较新的CSS量纲相除。共享CSS在原宽度上叠加这段微量同色宽度，避免覆盖万字、筒子等原有描边颜色。没有原描边的填充图形从`use`继承12%透明度的淡描边；新增整宽约0.2 CSS px，具体可见量还受图案自身变换影响。此处理不新增DOM或滤镜，SVG画布原有的内阴影继续保留；画布阴影与图案本身的描边分别检查，不能混为一谈。

三个牌面颜色、渐变停靠点和角度通过`@property`注册为可插值属性，避免对不可插值的背景图片设置过渡却仍直接跳色。悬停、选中和提示使用同一组120ms与`cubic-bezier(.2,.7,.2,1)`参数，手牌位移也复用它；原有悬停、选中与红中特殊悬停的颜色端点、停靠点和角度保持不变。静态倒角、接触暗部与牌内阴影不做几何过渡，尺寸在初始化和缩放时即时随牌框同步，避免牌宽改变后的阴影插值造成倒角比例漂移。外投影与光晕通过注册的`--tile-model-raised-opacity`按相同120ms参数从0到1渐入，各层原有透明度乘以该值，终态色彩、强度和范围不变；取消状态时立即换回牌内阴影，不保留外影退出动画，避免残影继续压到邻牌。减少动态效果设置仍关闭这些过渡。

`--tile-model-line-width: 1px`作为实体外边框与1px倒角的统一来源，不给原本无外边框的本家手牌额外增加边框。边线验收分别记录DPR 1/2/3下的CSS计算宽度与额外浏览器缩放量化：100%缩放以1 CSS px为目标，非100%缩放会受到浏览器used-width量化影响；透视、缩放与抗锯齿还会改变物理像素覆盖，不能声称任意条件下固定为1个物理像素。

## 区域档位与可见面

| 区域 | 强度 | 可见面 |
| --- | --- | --- |
| 本家手牌 | 1 | 4px厚度档；正面、2px顶面、最后两张2px右侧面；无底面 |
| 公开副露、亮出的他家手牌 | 0.8 | 3px厚度档；正面、1px顶面；副露末端一到两张1px右侧面 |
| 牌河 | 0.4 | 1px厚度档；正面、靠桌心1px窄边；无右侧面和底面 |
| 牌墙 | 0.6 | 2px厚度档；绿色背面或翻痞正面、1px顶边；不画下部象牙面 |
| 他家暗手牌背 | 0.6 | 复用牌墙2px档；绿色牌背、外框、内框浮雕、1px象牙薄层 |
| 选牌弹窗、结算手牌 | 1 | 复用手牌4px档；正面，用双层倒角表达轻厚度 |
| 出牌记录、提示行、顶栏痞子/癞子标记 | 0.4 | 复用牌河1px档；正面 |
| 发牌动画 | 与落位实牌相同 | 复制落位实牌计算材质，不维护独立分档；路径、时长和变换不变 |

厚度档由 `--tile-model-thickness` 控制体积投影范围，接触阴影透明度与厚度同向变化。厚度不直接增加外框或手牌宽高，外露细边控制在1–2px，原有SVG画布保留。

## 窄边与正面的圆润接缝

所有可见窄边复用同一套渐变与内侧高光。树脂侧面在原有1–2px宽度内，以暖白、浅绿、主绿和深绿等多个节点连接正面与牌背；径向釉面叠加上端偏亮、下端偏暗及中段反光，同时保留前后方向的明暗过渡，使窄边读作磨圆的弧面。顶面使用同样的多节点明暗过渡，在靠近正面的末端逐渐融入象牙色，避免直接换色。

有可见右侧面的牌在右上、右下角使用与牌框相同半径的径向过渡，环宽沿用原侧面宽度；暖白釉面在顶部与正面的切线处渐隐，避免矩形色条在圆角处截断或叠出双线。可见顶面的左右圆角同样使用径向环带与切线釉面，环宽从原顶面高度推导，小牌内径限制为非负值。弧形顶边与直顶边共用同一次光照判定，旋转后保持相同明暗。牌河、牌墙等只露顶边的区域复用这套共享过渡和圆角内高光，不额外增加右侧面或底面。正面牌与牌背分别通过 `--tile-model-coating`、`--tile-model-back-coating` 选择原有可见面，所有过渡均画在现有 `::after` 内，继续共用原来的四角9%轮廓，不增加DOM、图片、滤镜或绘制层，也不改各区域宽高、间距、可见面尺寸与点击范围。

## 朝向与光源

共同桌面坐标中，光来自右上方，暗部落向左下方。

牌河整张牌会按座位旋转 0°、-90°、180°、90°。其釉面角度、径向反光位置、倒角方向和三层投影向量使用相反旋转补偿。牌河局部顶边随牌一起旋转，始终指向桌心；外轮廓仅保留中性细线。

副露和牌墙等区域的牌体没有同样的整牌旋转，部分只旋转内部 SVG。此时材质保持原方向，不能再按 SVG 角度反旋转，否则会造成四家光照相反。

`observeTileMetrics()` 使用 ResizeObserver 读取现有牌框的实际宽高，按整牌 transform 反旋转光源向量与渐变峰值。只修改绘制变量，不增加 DOM，不按帧轮询。动画牌直接使用落位牌的材质快照，不再次计算光源。

四个角统一使用实牌短边的9%作为半径（横置7:5牌框使用高度作为物理牌宽），低于12%的上限，左右镜像对称且保留长方形观感。`--tile-model-radius` 是统一的单值半径，不再维护分角或软硬角变量；正面倒角、顶部/侧面涂层、牌面凹陷和交互描边共用轮廓。牌背内框统一从半径扣除内缩量，四角仍保持相同。

右上外倒角保持牌宽的2.5%，右缘次级倒角保持1.5%；左侧外倒角、内倒角和接触暗线分别限制在1px内。三层接地暗部继续使用原档位透明度与模糊宽度（牌宽×强度×2.5%/3.5%/9%），但使用负扩展量和反旋转的独立XY偏移，保留底缘原有接触深度，同时把左缘含模糊尾部的绘制范围收在1px内。顶面与右侧面的尺寸保持原值，材质使用前述共享圆润过渡；正面釉面、牌字凹陷与交互态外投影保持原值。

四角等半径的轮廓随牌自身旋转，不需要按角部方向补偿；移除原有角部判向函数与内部SVG的非对称圆角反旋转，SVG直接复用统一半径。整牌角度仍用于光源补偿，不改变图案、朝向和凹陷阴影。材质验证分别检查四家统一圆角、旋转后的角部对齐及独立光源补偿。

## 几何边界

普通态材质均在现有牌框内绘制。`.tile`、`.back` 和本家高优先级规则统一使用 `overflow:clip`、零 `overflow-clip-margin`，收住伪元素和旋转 SVG；自身阴影均为 inset。摸补标记改为内描边，翻痞描边也收在牌框内。牌区容器仍允许可见溢出，保证交互态的外投影与光晕不被裁掉。圆角和双层倒角不裁邻牌，也不增加覆盖层。

本家手牌单独使用 `clamp(.5px, .125 × ui-unit, 1px)` 的紧凑微缝；牌河继续保留原有1–2px间距。`paintHandSeams()` 在牌数、牌框尺寸变化后读取相邻实牌的边界，只给普通窄缝配置父容器 `::after` 的背景片段，宽度小于缝隙且不超过1px。两侧各内收1/64px以避开计算样式的小数序列化误差；渐变边缘更暗、中心略亮，位于牌列背后且不接收点击。待定牌的原间隔不画满，0/1张牌时没有多余片段。牌自身三层内阴影、顶部面、最后两张右侧面、双倒角及交互态外光晕均保持原值。

牌宽高、间距、格位、朝向、点击热区和规则保持原值；所有牌区按前述四角统一圆角处理，不新增 DOM、图片、滤镜或依赖。牌墙原有上下两层实体牌的叠墩关系保留，不能把实体叠墩与新增的阴影遮盖混为一谈。

旧 `--tile-depth`、`--tile-side` 仍被既有布局用于 SVG 尺寸和边框计算。它们保留为几何兼容量，不再驱动通用底面绘制。实际可见面由 `--tile-model-top-size`、`--tile-model-right-size` 和区域选择器控制；`--tile-model-bottom-size` 为零。

`src/ui/tile-material.js` 批量捕获落位牌的计算材质和现有两个伪元素，应用到已有飞牌克隆。捕获时还原浏览器used宽高精度，不复制不参与绘制的0px边框currentColor状态。发牌结束前后逐张核对53张牌的材质、厚度、纹理和SVG样式；出牌高亮直接复用牌河实牌，并核对前中后模型变量不变。

`tests/ui-tile-materials.mjs` 在三档尺寸下逐区对比修改前后的实际几何、SVG 尺寸、纹理、倒角和光源方向，弹窗及动画样例为仅用于展示的夹具。全部样式表加载完成后先触发既有resize布局入口，再测量副露等派生牌位，避免比较热换CSS期间的中间状态。CSS宽高、间距和朝向严格相等；投影矩形仅容许0.001px浮点尾差（小于1/64px布局量子），并记录每组最大偏差，避免重合成误报。动画内部SVG改为与落位实牌一致，外框保持原样。真实发牌过程由 `tests/ui-opening-deal.mjs` 验证。运行UI套件时设置 `KK_UI_SCREENSHOTS=0` 可禁用截图。

`tests/tile-paint-bounds.mjs` 读取实际投影四角、伪元素、SVG、自身阴影、描边与裁剪边界：普通绘制集合是原牌框的子集，新增邻牌相交面积为0；逐项检查选中、提示、最后出牌的外投影在取消后同步消失。该结论来自浏览器计算样式和几何边界证明，不使用截图或声称做了逐像素取样。

`tests/ui-tile-surface.mjs`针对曲面层强度、六类牌区共享主色、DPR与缩放下的边线、交互过渡，以及`use`引用实例中的图案描边做计算样式检查，同时核对源精灵图数据未改；此专项不产出截图，也不把CSS量化测量当作物理像素取样。

`tests/ui-hand-seams.mjs` 与提交 `c89e461` 对比三档尺寸、14/13/11/1/0张及副露/待定牌状态：逐张比较几何、牌面和可见面颜色，测量实际微缝及每段渐变的边界，验证渐变与任何牌框的相交面积为0，待定间隔和交互光晕不回归。四角一致、半径不超过物理牌宽12%、绘制层角部对齐与左侧明暗带另由 `tests/tile-material-checks.mjs` 在所有牌区、弹窗和动画样例中验证。
