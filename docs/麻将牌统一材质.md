# 麻将牌共享材质与可见面

所有正面、牌背复用 `tiles-depth.css` 中的 `resin-v2` 模型。区域规则只选择档位、可见面和整牌旋转补偿，不维护第二套釉面、倒角或接触阴影。

## 材质层

- `--tile-gloss`：低于 8% 的斜向釉面、两层低对比象牙质感和极轻的下沿暗化，位于透明 SVG 下方。
- `--tile-model-face-shadow`：右上亮、左下暗的外倒角，加次级内倒角。
- `--tile-model-edge-contact-shadow`：牌缘的窄接触暗影。
- `--tile-model-contact-shadow`：贴地 AO、主投影、远柔影。非手牌缩短投影，避免跨牌区投影。
- `--tile-model-edge-shadow`：顶面、侧面转角共用的连续内高光。
- 牌背使用相同的釉面与倒角，在绿色牌背变量上叠加外框高光、内框浮雕；暗手底部的象牙薄层不作为通用底面推广到牌墙。

## 区域档位与可见面

| 区域 | 强度 | 可见面 |
| --- | --- | --- |
| 本家手牌 | 1 | 正面、1–2px 顶面、最后两张的右侧面；无底面 |
| 公开副露、亮出的他家手牌 | 0.75 | 正面、窄顶面；副露末端一到两张露右侧面 |
| 牌河 | 0.8 | 正面、靠桌心的局部顶边；无右侧面和底面 |
| 牌墙 | 0.55 | 绿色背面或翻痞正面、窄顶边；不画下部象牙面 |
| 他家暗手牌背 | 0.65 | 绿色牌背、外框、内框浮雕、0.65px 象牙薄层 |
| 选牌弹窗、结算手牌 | 0.85 | 正面，用双层倒角表达轻厚度 |
| 出牌记录 | 0.7 | 正面 |
| 顶栏痞子/癞子标记 | 0.6 | 正面 |
| 发牌动画 | 0.65；本家正面为 1 | 按现有正面/牌背克隆选择材质，不改变动画路径、时长或变换 |

## 朝向与光源

共同桌面坐标中，光来自右上方，投影落向左下方。

牌河整张牌会按座位旋转 0°、-90°、180°、90°。其釉面角度、径向反光位置、倒角方向和三层投影向量使用相反旋转补偿。牌河局部顶边随牌一起旋转，始终指向桌心；外轮廓仅保留中性细线。

副露和牌墙等区域的牌体没有同样的整牌旋转，部分只旋转内部 SVG。此时材质保持原方向，不能再按 SVG 角度反旋转，否则会造成四家光照相反。

## 几何边界

材质均在现有牌框及伪元素内绘制。牌宽高、圆角、间距、格位、朝向、点击热区和规则由原布局控制，本模型不改这些取值，也不新增 DOM、图片、滤镜或依赖。

旧 `--tile-depth`、`--tile-side` 仍被既有布局用于 SVG 尺寸和边框计算。它们保留为几何兼容量，不再驱动通用底面绘制。实际可见面由 `--tile-model-top-size`、`--tile-model-right-size` 和区域选择器控制；`--tile-model-bottom-size` 为零。

`tests/ui-tile-materials.mjs` 在三档尺寸下逐区对比修改前后的实际几何、SVG 尺寸、渐变、倒角和光源向量，弹窗及动画样例为仅用于展示的夹具。真实发牌过程另由 `tests/ui-opening-deal.mjs` 验证。运行 UI 套件时设置 `KK_UI_SCREENSHOTS=0` 可禁用截图。
