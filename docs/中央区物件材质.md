# 中央区物件材质

基线de93787。只修改landscape.css、table-depth.css的绘制与共享变量，不改变任何牌区、中央区、方向字、骰子或头尾指示的尺寸、位置、圆角、transform、z-index与热区。

- 方向字：横屏可见的是#table-labels镜像，源字已隐藏。两处共用右亮左暗的字形内渐变与下缘1px微高光。CSS文字没有inset text-shadow，因此用background-clip:text和切口暗影模拟沉刻，不增加矩形框或复制文字。普通字主色#163b2e比台呢主色暗；当前行动者的#ffe8aa金字与源字#b7563e70底色不变，只补同色柔光。
- 骰子：两颗共用象牙白#fffdf7、暖灰白#f2eee4、浅暖灰#d8d4c9，右侧高光、左侧暗边。点数用右侧径向明暗与两层内影表达凹坑及下缘反光。较小点数的原金边宽度/偏移不变，仅把颜色提高到#ecd087；同点数时两颗都加金边，沿用原逻辑。
- 接触关系：保留上一轮按骰子宽8.5%推导的向左短影与面板边界；所有物件只改变材质层次，不改变叠放顺序。
- 头尾指示：保留原0×0边框三角的全部宽度、位置、content与层级，只让填充透明；在原border-box内用两条软斜线、顶部渐细线和低亮柔光画出描边。金色/青色沿用原语义，头尾重合仍优先青色。对应实牌的内环改成柔光，边框语义色不变。

全部只用渐变、text-shadow与box-shadow；没有新增DOM、图片、filter或backdrop-filter，每个元素/伪元素的box-shadow不超过两层。

## 验证

node tests/ui-center-materials.mjs：640×360、844×390、1280×720、1920×1080，四家当前行动者、骰子1至6点、相同点数双金边、头尾分开及重合。原始节点与可见镜像均读取计算样式，原三角以同边框几何的临时测量探针核对实际矩形，探针同步删除。对比完整牌区矩形与伪元素几何、DOM数量、颜色语义、材质一致性、方向光影、骰子影边界与两层阴影上限。

测试启动时只读取一次真实HTTP样式并记录SHA-256，对比时复用相同响应字节，避免每个场景重复下载。验证只读DOM/计算样式与解析渐变，不产出截图或做像素取样。
