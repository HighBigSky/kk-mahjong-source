# 牌面图案居中

图案始终以实际正面（.tile::before）为区域，不再用旧 --tile-side / --tile-depth 估计绘图区。牌框、模型厚度、圆角、排版、热区及图案源文件不变。

## 统一坐标

复用 src/ui/tile-material.js 已有的牌体测量，将扣除边框后的定位内容宽高CW、CH写入两项CSS变量；不增加观察器或动画。计算样式中的内容盒/边框盒和padding分别处理，保留浏览器1/64px布局精度。

正面内缩为L、T、R、B时：

- 正面宽 FW = CW - L - R，高 FH = CH - T - B。
- 图案中心为 (L + FW/2, T + FH/2)。
- 普通牌SVG视口为FW×FH；只旋转SVG的左右副露/牌墙交换为FH×FW，再按原90°/-90°朝向旋转。
- 已整体旋转的牌河不再叠加图案旋转。
- 手牌沿用自身正面实际顶面和最右两张的可见侧面内缩，普通牌、选中、提示及待定牌都走同一居中规则。

原SVG viewBox="0 0 60 84"与默认xMidYMid meet保持原样，缩放因子为min(视口宽/60,视口高/84)，留白成对相等，不拉伸图案、不更改路径、文字、花色或颜色。

## 文件

- tiles-depth.css：统一图案中心、视口与朝向变量，移除手牌单独的SVG定位。
- seats-layout.css、wall-layout.css、landscape.css：旧的SVG位置/宽高覆盖改为朝向与宽高交换变量。
- src/ui/tile-material.js：已有测量结果透出定位内容宽高，缓存同时考虑内容盒尺寸；绘制快照继续复制SVG计算样式，发牌动画沿用同一中心。
- tests/ui-tile-glyphs.mjs：以3ad9bd9为基线，比较牌体几何、完整内联symbol源与SVG标记、朝向、实际中心和等比绘制。
- 既有材质/光照测试保留牌框、边缘、阴影和UI的严格几何检查；SVG视口调整由居中专项覆盖，viewBox保持严格一致。

## 无截图验证

640×360、844×390、1920×1080；手牌、四家副露、四家牌河、四向翻痞牌墙、顶栏小牌、选牌弹窗、34种牌的出牌记录、结算手牌，以及选中/提示/待定状态。

使用同一牌框中的无绘制测量探针读取::before对应的实际投影矩形，再比较SVG getBoundingClientRect中心，两个方向均要求≤0.5px。牌框/牌区几何与修改前严格相等，SVG及symbol标记不变，原朝向不变。

实测修改前最大偏差约3.87px，集中在通用牌、牌河和旋转牌区；手牌原有局部面区居中已基本正确，不为对齐牌框而额外偏移。最终数值、所有命令与在线版本校验记录见output/tile-glyphs-report.md。

设置KK_UI_SCREENSHOTS=0，不生成截图；手机使用浏览器触屏模拟。几何与矩形中心验证不是对牌字墨迹的像素重心测量，原图案本身没有重画。
