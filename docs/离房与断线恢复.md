# 对局离房与断线恢复

- 主动点击「离开房间」：中止当前局，撤销离开者的身份；其他玩家返回原等待房间，真人重新准备，人机继续自动准备。保留已经结算的积分，下一次开局推进局数；新入座者从初始积分开始。最后一位真人离开时释放整房。
- 关闭页面、切网、断线：不视为主动离房，不移除座位、不交给人机。沿用原有断线宽限期，随后暂停对局；原身份恢复连接后继续原牌局。
- 标签页会话存储优先，本地存储备份用于关闭页面后重新打开。需使用同一浏览器、同一站点地址；清除站点数据、换浏览器或服务端重启清空内存房间后，不能恢复原局。
- 连接错误先允许原生 EventSource 恢复，再按 0.5 / 1 / 2 / 4 / 8 秒间隔显式重建，最大间隔 8 秒；每次收到真实状态后重置间隔。15 秒心跳不改变牌局版本，45 秒无任何消息或连接建立 12 秒未获快照则重新建立连接。
- 切回前台、页面从缓存恢复、网络重新上线时检查连接。房间面板断线时提供「重新连接」按钮；HTTP 恢复成功不等同于实时连接恢复，收到 SSE 快照后才重新开放游戏操作。
- 网络失败、超时、502 不删除身份。仅服务器确认 401 / 404 或成功离房才清理对应凭据；旧标签页不能清除另一标签页的新房间备份。断线时仍可通过 HTTP 主动离房；若离房请求失败，保留身份并允许重试。

## 涉及文件

- `src/server/rooms.js`：放开主动离房，复用积分/局数暂存和等待房间广播；心跳改为可监听事件。
- `src/network/client.js`：重试、超时检查、生命周期恢复、身份备份及失效清理。
- `app.js`：对局中允许离房，断线重连入口及恢复状态提示。
- `tests/room-leave-recovery.test.js`、`tests/client-recovery.test.js`：服务端状态与客户端故障回归。
- `tests/ui-room-recovery.mjs`：手机 844×390 触屏模拟、PC 1280×720 实际 HTTP/SSE 浏览器验收。可设置 `KK_VERIFY_URL` 验收部署后的站点，不依赖服务器内部状态。
- `tests/ui-opening-deal.mjs`：改为直接在进行中的对局离房，验证动画清理。

未改动引擎、发牌、吃碰杠胡判定及计分公式；没有新增依赖。

## 本轮验证

- 单元/服务端回归：257 项通过，包括重复离房、断线暂停、同身份恢复、积分沿用、过期身份清理和重试退避。
- Edge 155 浏览器：844×390 触屏模拟与 1280×720 PC 共 10 项场景通过；覆盖切网、手动重连、关闭标签页重开、对局离房、返回等待、新开局和 SSE 断开期间 HTTP 离房。
- 开局发牌动画 8 项浏览器回归通过；项目 TypeScript 检查和 JavaScript 语法检查通过。
- 未用实体 iOS / Android 手机验证；浏览器拒绝存储或用户清空站点数据时，无法恢复已丢失的身份。
