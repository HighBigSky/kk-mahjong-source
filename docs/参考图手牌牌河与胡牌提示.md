# 参考图展示调整

本轮只修改四家手牌/副露与牌河的摆法，以及胡牌提示。桌面相机、桌框宽高、木纹、绒布、灯光、背景、头像、顶栏、操作区和游戏规则保持原样；无新增依赖。

## 四家手牌与牌河

- 自己的手牌保持平直居中，摸到的牌沿用原来的右侧分隔；自己的副露移至手牌右侧。
- 对家为上方横排绿背，增加浅色顶沿；左右两家为沿桌沿的斜向竖排，角度对应参考图。左家副露位于牌列下端，右家副露位于牌列上端，暗手始终只显示牌背。
- 四块牌河向中央靠拢，围绕原有中央区域排列。每家仍预留 36 个固定格位，满牌时不截断、不滚动、不重叠。
- 真实弃牌数组及 DOM 节点继续保持出牌时间顺序。`src/ui/river-layout.js` 仅计算 CSS 格位，历史记录、最近弃牌和动画仍指向同一张实牌。

| 位置 | 第一张位置与填写顺序 | 换排方向 |
| --- | --- | --- |
| 自己 | 靠中央的第一排，从左到右 | 向自己的座位续排 |
| 对家 | 靠中央的第一排，从右到左 | 向对家的座位续排 |
| 右家 | 靠中央的第一列，从上到下 | 向右续列 |
| 左家 | 靠中央的第一列，从下到上 | 向左续列 |

## 胡牌提示

- 使用参考图的浅色浮窗和红色「胡」字，展示每种实际可胡牌的牌面、剩余未见张数和可接胡/仅自摸说明。
- 沿用原来的听牌计算、可见牌计数和候选排序；仍保留「打 X → 听 Y」说明以及多解切换。图片里的番数不是当前引擎的统一计分单位，本轮不据此新造番数或修改分值。
- 点击右上角「×」或按 Escape 收起。关闭状态在同一局的重绘、摸牌和服务器快照更新中保持，点击原有「提示」重新展开；新一局恢复默认展开。
- 重新展开只显示提示卡，不会选牌或出牌。已经展开时，原有「提示先高亮、再次确认才出牌」继续生效。
- 提示卡放在手牌右上方，有响应操作时收窄并向内移动，避开操作按钮。本家手牌始终留在提示卡下方。候选较多时只在卡内横向浏览，不滚动整个页面；关闭按钮固定可用。

## 修改文件

- `app.js`：分配牌河显示格位；绘制听牌牌面；管理关闭/展开状态，保留原输入与服务端命令。
- `src/ui/river-layout.js`：纯展示格位映射。
- `src/ui/play-assist.js`：集中新增提示卡文字，计算函数不变。
- `index.html`：增加提示卡、牌面列表、关闭按钮与无障碍标记。
- `landscape.css`：四家牌列、副露位置、中央牌河、提示卡样式。
- `tests/river-layout.test.js`、`tests/ui-play-assist.mjs`、`tests/ui-seated-view.mjs`：增加方向、容量、牌面、关闭保持、重新展开不出牌等验证。

## 验证与手测

浏览器：Edge 155；触屏为浏览器模拟，尚未逐机验证实体 iOS/Android。

- 手机横屏 640×360、844×390、780×360、800×360，PC 1920×1080：15 个满牌布局、20 个手牌数量、20 个真实 HTTP/SSE 输入场景通过。
- 原满牌验收：24 个布局场景及 24 个四方向弃牌动画场景通过，四家各 36 张压力弃牌完整可见，动画前后位置变化为 0；另外覆盖 PC 1280×720、1440×900。
- 胡牌提示：鼠标/触屏均验证实际牌面、剩余张数、关闭、Escape、重绘/同局快照后仍关闭、重新展开不出牌、别人回合已听时可查看、未听/已结束时隐藏。原特殊牌双击与提示二次确认回归通过。
- 房间/HUD：全屏 29 项、数字 216 项、手牌数量和副露组合 168 项通过，手牌最大中心误差 0.016px。
- 单元测试 231 项通过；项目及两个展示模块类型检查、`node --check app.js`、`git diff --check` 通过。

手测时先看四家少量弃牌是否按图围在中央，再连续出到换排观察四个方向。形成听牌后查看浮窗内牌面，点击「×」，继续摸打确认它保持收起，最后点击「提示」重新展开并确认没有自动出牌。
