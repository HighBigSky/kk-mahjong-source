# 部署到阿里云轻量（内地 · 纯 IP 访问 · 免备案）

本文是给本项目准备的最短路径。不需要 Docker、不需要宝塔、不需要域名、不需要 ICP 备案。
全程大约 15 分钟，装完得到一个固定地址：`http://公网IP`（监听 80 端口，地址不带端口号）。

> 备案是给「域名」用的，不是给「IP」用的。用 `http://公网IP:端口` 对外服务不涉及域名，
> 所以不需要备案；只有以后想用 `https://你的域名.com` 时才需要（大陆地域约 1–3 周）。

---

## 一、买服务器

| 项目 | 选择 |
|---|---|
| 产品 | **轻量应用服务器** |
| 地域 | **武汉**（同省，5–15 ms）；没有就选 **杭州 / 上海**（约 20–35 ms） |
| 类型 | 通用型 |
| 配置 | 2核2G 最稳；预算紧选 2核1G 也能跑 |
| 系统盘 | 30 GB 足够 |
| 镜像 | **系统镜像 → Ubuntu 24.04 LTS**（不要选宝塔面板镜像） |
| 时长 | 先买 1 个月试，稳定后再年付 |

**不要**选「香港及海外」里的节点：那是给境外玩家用的，国内两人对局会多几十毫秒的来回。
也不要选深圳/广州/北京/青岛，离湖北更远。

买好之后立刻做一件事：**控制台 → 轻量应用服务器 → 防火墙 → 添加规则**

| 应用类型 | 协议 | 端口 | 说明 |
|---|---|---|---|
| 自定义 | TCP | 80 | 游戏端口；阿里云默认已放行，确认一下 |
| 自定义 | TCP | 22 | SSH，最好限定来源为你的公网 IP |

没有 80 端口这一步，外网一定打不开，别先怀疑代码。
如果 80 被占用或想留作他用，也可以改用 5173：安装时加 `PORT=5173`，并把防火墙放行 5173。

## 二、上传项目

已经打好一个 118 KB 的运行时包（28 个文件，不含测试和截图，已验证解压即可运行）：
`deploy/kk-mahjong-runtime.tar.gz`

在 Windows 上于项目根目录（`D:\麻将`）打开终端：

```powershell
scp .\deploy\kk-mahjong-runtime.tar.gz root@公网IP:/opt/
ssh root@公网IP
mkdir -p /opt/kk-src && tar -xzf /opt/kk-mahjong-runtime.tar.gz -C /opt/kk-src && ls /opt/kk-src
```

首次连接会问 `yes/no`，输 `yes`，然后输服务器 root 密码。
没有 `scp` 就用 **WinSCP** 把同一个 tar.gz 拖到 `/opt/`，再执行后面的解压命令。

> 包里只含运行所需文件。`tests/`、`output/`、`docs/` 不参与运行。
> 也可以不用压缩包，直接 `scp -r` 上传 `server.js package.json index.html app.js engine.js *.css src assets deploy`，效果相同。

## 三、一键安装

```bash
ssh root@公网IP
cd /opt/kk-src
PORT=80 bash deploy/install.sh
```

`PORT=80` 让服务直接监听 80，访问地址就不带端口号。不写这个变量则默认 5173。

脚本会自动完成：

1. 检查/安装 Node 18+（缺就装 Node 20 LTS）
2. 建一个无登录权限的 `kk` 用户
3. 把运行时文件复制到 `/opt/kk-mahjong`
4. 写入 systemd 服务并设为开机自启、崩溃自动重启；授予 `CAP_NET_BIND_SERVICE` 让非 root 用户也能绑 80
5. 自检 `/healthz` 和首页
6. 放行本机 ufw（如果有）

成功后会打印：

```
 访问地址：http://你的公网IP
```

## 四、验收（不要跳）

1. 电脑浏览器打开 `http://公网IP`，应看到 KK麻将 建房页
2. **手机关 Wi-Fi 用 4G 打开同一地址**，建房、加人机、开局，确认不是只有本机能访问
3. 两个浏览器各开一个，验证四人桌同步

## 五、日常运维

```bash
systemctl status kk-mahjong     # 状态
journalctl -u kk-mahjong -f     # 实时日志
systemctl restart kk-mahjong    # 重启（内存里的房间会清空，牌局请先结束）
```

**不要在牌局进行中重启**：房间、身份令牌、积分都只在内存里，重启即丢。

更新代码：重新上传文件 → `bash deploy/install.sh`（脚本会停服、覆盖、重启）。

## 六、以后想加域名和 HTTPS

当前是 HTTP + IP，够玩，但有两处降级：

- 浏览器地址栏显示「不安全」
- 「复制邀请」按钮会失败，退化为弹出文本框手动复制（功能仍可用）

如果想升级：买个便宜域名（`.top`/`.xyz` 首年十几块），解析 A 记录到公网 IP，然后按
`deploy/Caddyfile.example` 里的步骤装 Caddy，它会自动申请并续期证书。记得在那个服务里加上
`Environment=PUBLIC_ORIGIN=https://你的域名`。

大陆地域用域名**必须先做 ICP 备案**（阿里云控制台 → 备案，个人备案约 1–3 周，免费），
否则 80/443 会被拦截。备案期间继续用现在的 IP 地址玩，不受影响。

## 七、常见问题

| 现象 | 原因与处理 |
|---|---|
| 外网打不开，服务器上 `curl 127.0.0.1/healthz` 正常 | 阿里云控制台防火墙没放行 80（或你改的端口） |
| 启动报 `EACCES` / 绑定 80 失败 | systemd 单元缺少 `AmbientCapabilities=CAP_NET_BIND_SERVICE`，重跑 `PORT=80 bash deploy/install.sh` |
| `install.sh` 报 Node 版本过低 | 系统自带 Node 太旧，脚本会自动装 Node 20；若失败可 `curl -fsSL https://deb.nodesource.com/setup_20.x \| bash -` |
| 服务起不来 | `journalctl -u kk-mahjong -n 50 --no-pager` 看具体报错 |
| 页面能开但牌桌更新一顿一顿 | 检查是否又挂了一个会缓冲 SSE 的反向代理，必须 `flush_interval -1` / `proxy_buffering off` |
| 好友进不来房间 | 房间码只在同一台服务器内有效，确认大家访问的是同一个公网地址 |
| 80 端口被运营商/备案策略拦截 | 换回高位端口：`PORT=8080 bash deploy/install.sh`，同时防火墙放行 8080 |

## 八、安全提醒

- 安全组只放行必要端口，`22` 最好限制来源 IP
- 不要装宝塔/1Panel 之类的面板，本服务不需要，多一个公网管理入口就多一份风险
- 房间码不是密码，只发给自己人
- 服务已启用 `NoNewPrivileges`、`ProtectSystem=strict`，以非 root 用户运行

## 九、更新代码（改了游戏之后怎么上线）

**永远在本地 `D:\麻将` 改代码，改完用一条命令推上去。** 不要直接改服务器上的文件——下次更新会被整个覆盖。

### 一键更新

双击 `deploy\更新到服务器.cmd`，或在项目根目录执行：

```powershell
.\deploy\update.ps1
```

它做四件事：

1. 把运行时文件打包成 118 KB 的 tar.gz
2. 上传到服务器 `/opt/`
3. 先备份现有版本到 `/opt/kk-backup-<时间戳>.tar.gz`，再解压、重装
4. 从外网自检 `/healthz` 和首页，都 200 才算成功

参数可以用命令行覆盖：

```powershell
.\deploy\update.ps1 -Server 47.122.110.77 -Port 80
```

### 更新期间的影响

服务会重启，**服务器内存里的房间、座位、积分全部清空**，正在打牌的人会掉线。
所以：等这一桌打完再更新；更新完大家重新建房、换个房间码。

一次更新大约 50–90 秒，其中真正的停机只有 1–2 秒。

### 回滚

每次更新前的备份路径会在输出里打印，例如：

```
BACKUP=/opt/kk-backup-20261017-162416.tar.gz
```

回滚一条命令：

```bash
ssh -i 你的密钥 root@47.122.110.77 \
  "rm -rf /opt/kk-mahjong && tar -xzf /opt/kk-backup-20261017-162416.tar.gz -C /opt && systemctl restart kk-mahjong"
```

备份每个约 120 KB，攒多了可以删旧的：

```bash
ls -lt /opt/kk-backup-*.tar.gz | tail -n +6 | xargs -r rm
```

### 哪些改动需要更新

| 改了什么 | 要不要走更新流程 |
|---|---|
| `app.js` / `*.css` / `src/network/` / `src/ui/` | 要（前端文件，刷新即生效） |
| `engine.js` / `src/server/` / `src/domain/` / `server.js` | **要**（服务端规则，必须重启） |
| `assets/` 里的图片、SVG | 要 |
| `package.json` | 要（目前没有依赖，基本不用改） |
| `docs/`、`tests/`、`output/` | 不需要（不进部署包） |

### 改了规则之后要重开的服务

```bash
systemctl restart kk-mahjong
```

`update.ps1` 已经帮你做了，手工改服务器配置时才需要自己敲。
